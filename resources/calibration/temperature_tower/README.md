# Temperature tower

`temperature_tower_floor.amf` is a floor of the "Smart compact temperature calibration tower" by gaaZolee,
https://www.thingiverse.com/thing:2729076, licensed under the Creative Commons Attribution-ShareAlike 3.0 Unported
license, see `LICENSE.txt`. The file is taken unmodified from SuperSlicer
(`resources/calibration/filament_temp/Smart_compact_temperature_calibration_item.amf`).

Calibration > Temperature Tower adapts the work: it stacks one floor per temperature, scales the floors with the nozzle
diameter and embosses the temperature of each floor on its front face, see `src/libslic3r/TemperatureTower.cpp`.
The adapted tower is distributed under the same license.
